# TurismoUQ – Bases de Datos II

Base de datos de una plataforma de reservas turísticas del Quindío (Oracle XE 21c).

## Orden de ejecución

1. `00_CrearUsuario.sql` (como SYSTEM)
2. `01_TablasRestricciones.sql`
3. `02_CargaDatos.sql`
4. `03_ConsultasAnalisis.sql`
5. `04_PaqueteTurismoUQ.sql`
6. `05_Disparadores.sql`
7. `06_TablespaceVistaMaterializada.sql`
8. `07_PruebasEntrega2.sql`

Los scripts 01 a 07 se ejecutan conectados como el usuario TURISMOUQ.
